# ElevenLabs Creator ১ মাস ফ্রি — বাংলা গাইড

Hacktoberfest-এর অফার দিয়ে **ElevenLabs Creator প্ল্যান এক মাস ফ্রি** নেওয়ার ধাপে ধাপে বাংলা গাইড।
প্রতিটা ধাপে স্ক্রিনশট আছে, আর ছবিতে মার্ক করা আছে কোথায় চাপ দিতে হবে।

### 👉 গাইডটা পড়ুন: **https://jobayermannan.github.io/elevenlabs-free-guide/**

ফ্রি, সবার জন্য খোলা। কাজে লাগলে শেয়ার করুন।

---

## এক নজরে

| ধাপ | কী করবেন |
| --- | --- |
| ১ | `hacktoberfest.com/my/promos` পেজে যান |
| ২ | MyMLH অ্যাকাউন্ট খুলুন, ইমেইল ভেরিফাই করুন |
| ৩ | ElevenLabs অফারে **Get your code** চাপুন |
| ৪ | দুইটা শর্ত দেখে নিন |
| ৫ | MyMLH-এ ফোন নম্বর ভেরিফাই করুন |
| ৬ | MyMLH-এ GitHub অ্যাকাউন্ট কানেক্ট করুন (না থাকলে খুলে নিন) |
| ৭ | কোড নিয়ে ElevenLabs-এ রিডিম করুন |

## ⚠️ নিরাপত্তা

পুরো কাজটা **নিজের ফোনে নিজে** করবেন। **OTP, verification code বা পাসওয়ার্ড কাউকে দেবেন না** — কেউ চাইলে বুঝবেন সেটা স্ক্যাম।

## এই রিপোতে কী আছে

```
index.html              গাইডের পুরো পেজ (একটাই ফাইল, কোনো বিল্ড লাগে না)
assets/step-*.png       মার্ক করা স্ক্রিনশট
tools/annotate.py       স্ক্রিনশটে মার্ক বসানোর স্ক্রিপ্ট (Pillow লাগে)
```

আসল (মার্ক ছাড়া) স্ক্রিনশটগুলো ইচ্ছে করেই রিপোতে রাখা হয়নি — ওগুলোতে ব্যক্তিগত তথ্য ছিল,
যেটা `step-*.png`-এ ঢেকে দেওয়া হয়েছে। তাই `tools/annotate.py` চালাতে হলে নিজের স্ক্রিনশট
`assets/1.png` … `assets/5.png` নামে রাখতে হবে।

লোকালি দেখতে চাইলে:

```bash
python -m http.server 8000
```
