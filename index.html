ElevenLabs Creator প্ল্যান ১ মাস ফ্রি — ধাপে ধাপে

Hacktoberfest-এর অফার দিয়ে ElevenLabs-এর Creator প্ল্যান এক মাস ফ্রি পাওয়া যায়। কোনো ক্রেডিট কার্ড লাগে না। নিচের প্রতিটা ধাপে স্ক্রিনশট দেওয়া আছে আর ছবিতে মার্ক করা আছে কোথায় চাপ দিতে হবে — দেখে দেখে নিজেই করে ফেলতে পারবেন।

শুরুর আগে

কী কী লাগবে

  • একটা ইমেইল, যেটাতে আপনি এখনই লগইন করতে পারেন (Gmail হলে সবচেয়ে সহজ)।
  • আপনার নিজের মোবাইল নম্বর — SMS ভেরিফিকেশনের জন্য।
  • একটা GitHub অ্যাকাউন্ট। না থাকলে সমস্যা নেই, ধাপ ৬-এ খোলা শেখানো আছে।
  • হাতে ১৫–২০ মিনিট সময় আর ভালো ইন্টারনেট।
🔒

OTP বা পাসওয়ার্ড কাউকে দেবেন না। এই পুরো কাজটা আপনি নিজের ফোনে নিজেই করবেন। Makezy সহ কেউই আপনার কাছে OTP, verification code বা পাসওয়ার্ড চাইবে না। কেউ চাইলে বুঝবেন সেটা স্ক্যাম।

ধাপগুলো এক নজরে

  1. Hacktoberfest-এর প্রোমো পেজে যান
  2. MyMLH অ্যাকাউন্ট খুলুন ও ইমেইল ভেরিফাই করুন
  3. ElevenLabs অফারে “Get your code” চাপুন
  4. দুইটা শর্ত দেখে নিন
  5. MyMLH-এ ফোন নম্বর ভেরিফাই করুন
  6. MyMLH-এ GitHub অ্যাকাউন্ট কানেক্ট করুন
  7. কোড নিয়ে ElevenLabs-এ রিডিম করুন
১

ধাপ ১

Hacktoberfest-এর প্রোমো পেজে যান

ব্রাউজারে গিয়ে এই লিংকটা খুলুন — hacktoberfest.com/my/promos। চাইলে সরাসরি এখানে চাপ দিন।

আপনি লগইন করা না থাকলে পেজটা নিজে থেকেই আপনাকে MLH-এর ওয়েবসাইটে নিয়ে যাবে। সেখানে কী করতে হবে সেটা ধাপ ২-এ আছে। লগইন করা থাকলে নিচের ছবির মতো পেজটা দেখতে পাবেন।

২

ধাপ ২

MyMLH অ্যাকাউন্ট খুলুন ও ইমেইল ভেরিফাই করুন

লিংকটা আপনাকে MLH-এর লগইন পেজে নিয়ে যাবে। আগে থেকে অ্যাকাউন্ট না থাকলে Sign up বা Create account-এ চাপ দিন, তারপর:

  1. Google দিয়ে সাইন আপ করুন — এটাই সবচেয়ে দ্রুত। অথবা যেকোনো ইমেইল আর একটা নতুন পাসওয়ার্ড দিন।
  2. ফর্মে নাম, জন্মতারিখ, দেশ — এসব সাধারণ তথ্য চাইলে পূরণ করুন।
  3. MLH আপনার ইমেইলে একটা confirmation মেইল পাঠাবে। ইনবক্সে গিয়ে লিংকে চাপ দিয়ে ইমেইলটা ভেরিফাই করুন।
  4. মেইল না পেলে Spam বা Promotions ফোল্ডার দেখুন।
💡

পাসওয়ার্ডটা মনে রাখুন। পরের ধাপগুলোতে MyMLH-এ আবার ঢুকতে হবে। Google দিয়ে সাইন আপ করলে এই ঝামেলা নেই।

ইমেইল ভেরিফাই হয়ে গেলে আবার hacktoberfest.com/my/promos পেজে ফিরে আসুন। এবার কোড আর অফারের তালিকাটা দেখতে পাবেন।

৩

ধাপ ৩

ElevenLabs অফারে “Get your code” চাপুন

প্রোমো পেজে নিচের দিকে স্ক্রল করলে অনেকগুলো অফার পাবেন। খুঁজে বের করুন “ElevenLabs – 1 Month Free” লেখা কার্ডটা, আর ডান পাশের Get your code বাটনে চাপ দিন।

৪

ধাপ ৪

দুইটা শর্ত দেখে নিন

কার্ডের নিচে লাল রঙে দুইটা লাইন লেখা থাকে। দুইটাই পূরণ না হলে কোড পাবেন না:

  • Needs a verified phone number on MyMLH — আপনার মোবাইল নম্বর ভেরিফাই করা নেই।
  • Needs a connected GitHub account on MyMLH — GitHub অ্যাকাউন্ট কানেক্ট করা নেই।

লাইন দুইটার শেষে Verify it আর Connect it লেখা লিংক আছে। ওখানে চাপ দিলেই সোজা MyMLH-এর ঠিক জায়গায় চলে যাবেন। পরের দুই ধাপে এই দুইটাই করব।

📋

কার্ডে “All codes have been claimed for now.” লেখা থাকতে পারে — মানে ওই মুহূর্তে কোড শেষ। তখন ঘাবড়ানোর কিছু নেই: শর্ত দুইটা আগেই পূরণ করে রাখুন, আর নতুন কোড ছাড়লে সাথে সাথে নিতে পারবেন। দিনে কয়েকবার পেজটা দেখুন।

৫

ধাপ ৫

MyMLH-এ ফোন নম্বর ভেরিফাই করুন

Verify it লিংকে চাপ দিলে MyMLH-এর প্রোফাইল পেজ খুলবে। নিচে স্ক্রল করে Phone লেখা বক্সটা খুঁজুন, তারপর ডান পাশের Add new বাটনে চাপ দিন।

নম্বর দেওয়ার নিয়ম

  1. দেশ হিসেবে Bangladesh (+880) বেছে নিন।
  2. নিজের নম্বরটা লিখুন। প্রথম শূন্য বাদ দিয়ে লিখবেন — যেমন 01712345678 হলে +880 1712345678।
  3. আপনার ফোনে SMS-এ একটা কোড আসবে। সেই কোডটা MyMLH-এর ঘরে নিজে লিখুন।
  4. ভেরিফাই হয়ে গেলে Phone বক্সে আপনার নম্বরটা দেখা যাবে।
🔒

SMS-এ আসা কোডটা শুধু আপনার। এটা MyMLH-এর ওয়েবসাইট ছাড়া আর কোথাও লিখবেন না, কাউকে বলবেন না — ফোনে, মেসেজে বা স্ক্রিন শেয়ারেও না।

ধাপ ৬

MyMLH-এ GitHub অ্যাকাউন্ট কানেক্ট করুন

একই প্রোফাইল পেজে আরেকটু নিচে Social Media Connections লেখা বক্স আছে। ডান পাশের Add new-এ চাপ দিলে ছোট একটা মেনু নামবে — সেখান থেকে GitHub বেছে নিন।

এরপর GitHub-এর একটা পেজ আসবে, সেখানে Authorize বা Continue বাটনে চাপ দিলেই কানেক্ট হয়ে যাবে। GitHub-এ লগইন করা না থাকলে আগে লগইন চাইবে।

GitHub অ্যাকাউন্ট না থাকলে

প্রথমে একটা অ্যাকাউন্ট খুলে নিন — github.com/signup। পুরো কাজটা দুই মিনিটের, আর একদম ফ্রি।

  • Password: কমপক্ষে ১৫ অক্ষর, অথবা ৮ অক্ষরের মধ্যে একটা সংখ্যা আর একটা ছোট হাতের অক্ষর রাখতে হবে।
  • Username: ইংরেজি অক্ষর, সংখ্যা আর - চলে। এখানে ইমেইল লিখবেন না — যেমন jobayer-dev।
  • শেষে ইমেইলে আসা কোড দিয়ে অ্যাকাউন্টটা ভেরিফাই করুন।

অ্যাকাউন্ট হয়ে গেলে MyMLH-এ ফিরে গিয়ে উপরের নিয়মে GitHub কানেক্ট করুন।

ধাপ ৭

কোড নিয়ে ElevenLabs-এ রিডিম করুন

  1. আবার hacktoberfest.com/my/promos পেজে যান। দরকার হলে পেজটা রিফ্রেশ করুন (F5)।
  2. ElevenLabs কার্ডে লাল লেখা দুইটা এখন আর থাকবে না।
  3. Get your code-এ চাপ দিন। কোডটা দেখাবে — কপি করে কোথাও সেভ করে রাখুন।
  4. elevenlabs.io-তে অ্যাকাউন্ট খুলুন বা লগইন করুন।
  5. সেখানে Subscription বা Billing পেজে গিয়ে কোডটা বসিয়ে দিন।
  6. Creator প্ল্যান চালু হয়েছে কিনা নিজের অ্যাকাউন্টে দেখে নিন।
ℹ️

একটা অ্যাকাউন্টে একটাই কোড চলে, আর কোডগুলো একটার সাথে আরেকটা যোগ হয় না। ক্রেডিট কার্ড লাগে না। অফারের শর্ত ElevenLabs আর MLH ঠিক করে, তারা যেকোনো সময় বদলাতে পারে।

প্রশ্ন ও উত্তর

আটকে গেলে

“All codes have been claimed” দেখাচ্ছে, কী করব?
ওই মুহূর্তে কোড শেষ। শর্ত দুইটা (ফোন + GitHub) আগেই পূরণ করে রাখুন, তাহলে নতুন কোড ছাড়লে সাথে সাথে নিতে পারবেন। দিনে কয়েকবার পেজটা রিফ্রেশ করে দেখুন।
লাল লেখা দুইটা এখনো যাচ্ছে না।
পেজটা রিফ্রেশ করুন। তারপরও থাকলে MyMLH-এর প্রোফাইলে গিয়ে দেখুন নম্বরটা সত্যিই ভেরিফাই হয়েছে কিনা আর GitHub কানেক্ট দেখাচ্ছে কিনা। দুইটা ঠিকমতো হওয়ার পর এক-দুই মিনিট সময় লাগতে পারে।
SMS কোড আসছে না।
নম্বরটা +880 দিয়ে ঠিকভাবে লিখেছেন কিনা দেখুন (শুরুর শূন্য বাদ)। নেটওয়ার্কের কারণে দেরি হতে পারে, কয়েক মিনিট পরে আবার Resend চাপুন। বারবার না হলে অন্য একটা অপারেটরের নম্বর দিয়ে দেখুন।
GitHub কানেক্ট করলে কি আমার কোড বা রিপো ওরা দেখতে পাবে?
MyMLH শুধু আপনার পাবলিক প্রোফাইলের তথ্যটুকু নেয় — কে আপনি, সেটা মেলানোর জন্য। Authorize করার আগে GitHub নিজেই কী কী অনুমতি চাওয়া হচ্ছে স্ক্রিনে দেখিয়ে দেয়, পড়ে নিতে পারেন। পরে চাইলে GitHub-এর Settings → Applications থেকে অনুমতিটা তুলে নিতে পারবেন।
একাধিক অ্যাকাউন্ট খুলে কয়েকটা কোড নেওয়া যাবে?
না। প্রতি ব্যক্তি একটা কোড, আর এক অ্যাকাউন্টে একটাই কোড চলে। একাধিক ভুয়া অ্যাকাউন্ট খুললে অ্যাকাউন্ট বন্ধ হয়ে যেতে পারে।
কেউ আমার হয়ে কাজটা করে দিতে চাইলে?
অ্যাকাউন্ট আর ভেরিফিকেশনটা নিজের ফোনে নিজেই করুন। কেউ সাহায্য করলেও OTP, পাসওয়ার্ড বা verification code তাকে দেবেন না — এগুলো দিয়ে আপনার অ্যাকাউন্টের দখল নিয়ে নেওয়া যায়।
